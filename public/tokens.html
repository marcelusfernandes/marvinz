Typography

Sizes in rem (base = 14px). Apply line-height + weight independently.

--font-size-xs · 0.714rem (10px)
Status badge captions
--font-size-sm · 0.857rem (12px)
File tree row, tab label, modal hint
--font-size-md · 1rem (14px)
Default body text, editor content
--font-size-lg · 1.143rem (16px)
Section headers, sidebar group titles
--font-size-xl · 1.429rem (20px)
Modal titles, page headings

Families — system font stack (nenhum arquivo de fonte baixado). O browser resolve a primeira opção disponível no SO:
macOS: SF Pro / SF Mono · Windows: Segoe UI / Consolas · Linux: Roboto ou fallback genérico.

--font-family-sans
SF Pro (macOS) · Segoe UI (Win) · Roboto (Linux)
--font-family-mono
